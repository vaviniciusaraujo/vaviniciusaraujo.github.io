# Vinicius Araujo — Portfolio

Static site, no build step. Upload the contents of this folder to any static host
(Netlify, Vercel, GitHub Pages, Cloudflare Pages, or any web server).

## Structure

```
index.html                 Home (carousel, selected works, about)
works/ art/ lab/           Category pages (grid of project cards)
works/<project>/index.html One page per project (gallery of images and videos)
404.html                   Not-found page
css/style.css              Site styles
css/custom.css             Styles made in the visual editor (Estilos panel) — shared by all pages
js/main.js                 Hero animation, carousel, video autoplay, prev/next, smooth scroll
assets/projects/<project>/ Project media (.mp4 + poster, .webp + .jpg)
assets/img/                Home / carousel images
favicon.ico, site.webmanifest, robots.txt, sitemap.xml (sitemap is regenerated by the editor)
```

Paths are root-absolute (`/css/...`, `/works/...`), so the site must be served from the root of a
domain (Netlify, Vercel, Cloudflare Pages, GitHub Pages with a custom domain). Preview locally with
the editor or `python -m http.server` inside this folder — opening the .html file directly won't work.

## Source folders and import

The original renders live outside this folder, in `site 2026/works`, `site 2026/art` and `site 2026/lab`.
`editor/tools/import_projects.py` picked, compressed and laid out the media from those folders
(latest version of each shot, videos to H.264 without audio, posters, duplicates removed).
New projects are best added through the editor (Works / Art / Lab page → “+ Projeto”).

## Publishing

Published with GitHub Pages at https://viniciusaraujova.com — the workflow in
`.github/workflows/pages.yml` (repository root) deploys this folder on every push to `main`.

## Editar o site (editor visual)

Dois cliques no atalho **Editar site** (na pasta `site 2026`), ou:

```
python editor/server.py
```

Abre http://localhost:8080 com o editor. Clique nos textos para editar, passe o mouse nas fotos
para trocar/redimensionar/mover, arraste imagens do computador para a página, e salve com Ctrl+S.
Cada salvamento guarda a versão anterior em `editor/backups/` (botão "Versões").

A pasta `editor/` fica fora de `portfolio/` e nunca vai para o site publicado.
Para ver o site sem o editor: http://localhost:8080/?preview

## Adding a work image by hand (without the editor)

1. Export at ~1200px on the long side, save a `.webp` and a `.jpg` into `assets/img/`.
2. Copy an existing `<figure class="ph">` block in `index.html`, update the file names, `alt`,
   `width`/`height`, and its `grid-column` / `aspect-ratio`.
3. To show it in the hero carousel, add its path to the `data-images` attribute of `.car` in `index.html`.
